# Sidhardha Valavala

Full-stack developer portfolio. The live site is [sidhardha-portfolio.vercel.app](https://sidhardha-portfolio.vercel.app).

The page covers work, skills, certificates, and selected projects. Skills are a 3D keyboard. Project write-ups open in a dialog, and the contact note opens WhatsApp.

## Stack

Next.js, React, TypeScript, Tailwind CSS, and Three.js.

## Run locally

```bash
corepack pnpm install
corepack pnpm dev
```

Open [http://localhost:3000](http://localhost:3000).

Copy `.env.example` to `.env` only if the contact form should send email through Resend. With no key, the form opens WhatsApp.
